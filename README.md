# Clinical Trial Simulator

Design a fictional Phase I-III trial and see the consequences of your choices.

**Live demo:** https://macaly-lh2v5xxurjd9v3agyfu7x9yg-prod.macaly-app.com

> This is a fictional, educational demonstration. Do not use it for real patient data, clinical decisions or regulatory submissions.

## Features
- Choose dosing, endpoints, comparators and sample size
- Branching consequences tied to trial-design principles
- Regulatory divergence across authorities

## Tech stack
Built on Macaly Cloud.
